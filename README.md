# 옥토퍼스 운영콘솔 목업

바로고 **옥토퍼스(Octopus)** — 딜리버리 마스터용 운영콘솔 프로덕트 목업입니다.
12개 화면(주문 현황·라이더 관제 / 대시보드 / 책임권역 / 수익 / 구상권 / 정산 / 출금 / 완료 주문 / 통계 / 상점 등록 / 담당 상점 / 서브계정)과 **개발 명세 오버레이**를 하나의 HTML에 담았습니다.

## 구성

```
index.html          운영콘솔 목업 (자체 완결형, 372KB)
logo/               배달대행사 로고 — 바로고 · 모아라인 · 딜버
store_logo/         브랜드 로고 — 버거킹 · 맥도날드 · 스타벅스 · 올리브영 · 요기배달
bank_logo/          은행 로고 — 신한은행
font/               Pretendard Variable (OFL 1.1, LICENSE.txt 동봉)
.nojekyll           Jekyll 빌드 비활성화
```

경로는 전부 상대경로라 저장소 루트든 하위 폴더든 그대로 동작합니다.

## 배포

GitHub Pages — **Settings → Pages → Source: Deploy from a branch → `main` / `(root)`**

→ https://kimkc1968.github.io/octopus-mockup/

```bash
git add -A
git commit -m "운영콘솔 목업 갱신"
git push
```

경로는 전부 상대경로라 하위 폴더로 옮겨도 그대로 동작합니다.

## ⚠️ 카카오맵 도메인 등록 (필수)

주문 현황의 라이더 관제와 책임권역 화면은 **카카오맵 JavaScript SDK**를 씁니다.
JavaScript 키는 **도메인 화이트리스트**로 보호되므로, GitHub Pages 주소를 등록하지 않으면 **지도가 통째로 뜨지 않습니다.**

1. [Kakao Developers](https://developers.kakao.com) → 내 애플리케이션 → 해당 앱
2. **앱 설정 → 플랫폼 → Web → 사이트 도메인**에 아래를 추가

```
https://kimkc1968.github.io
```

> 경로(`/octopus-mockup/`)는 빼고 **도메인까지만** 등록합니다.
> 로컬에서도 열어본다면 `http://localhost:4000` 을 함께 등록하세요.

JavaScript 키는 브라우저에 노출될 수밖에 없는 키라 저장소 공개 자체는 문제가 아닙니다. **도메인 제한이 유일한 보호 수단**이므로, 등록 도메인을 필요한 것만 남겨 두세요.
